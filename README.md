# Customer Churn Analysis

## 1. Project Overview

This Project analyzes customer churn data to understand customers retention and identify churn patterns.

## 2. Business Objectives

- Analyze customer churn patterns.
- Understand customer retention.
- Identify factors associated with churn.
- Support data-driven business decisions.

 ## 3. Tools and Technologies
 
 - SQL
 - Microsoft Power BI
 - DAX
 - CSV Dataset

## 4. Dataset

- Cleaned Dataset:
  Clean_Churn_Data.csv

## 5. SQL Analysis
SQL queries are used to analyze customer churn data.
- SQL File: Churn_Analysis.sql

## 6. DAX Measures

DAX measures are used for calculations in the Power BI dashboard.
- DAX File:
 Custommer_Churn_Analysis_DAX_Queries.txt

 ## 7. Power BI Dashboard

 The dashboard presents customer churn analysis through visualizations.
 - Dashboard File:
   Customer_Churn_Analysis_Dashboard.pbix
   
Download the PBIX file and open it in Power BI Desktop.

## 8. Key Insights

The project explores customer churn patterns and retention trends.

## 9. Business Recommendations

- Monitor customer churn regularly.
- Investigate customer groups with higher churn.
- Use data-driven strategies to improve retention.
